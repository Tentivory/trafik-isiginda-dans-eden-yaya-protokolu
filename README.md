# Trafik Isiginda Dans Eden Yaya Protokolu

> Resmi uyari: Bu depo, uluslararasi yaya hukukunun **en az okunan** maddesini uygulayan referans gerceklemedir.

## Nedir bu?

Dunya genelinde yayalar kirmizi isikta durur. Bu proje durmaz.  
Durmaz ama **rastgele folklorik bir hareket** sergiler.  
Cunku bir kavsak, yeterince iddiali bakilirsa, acik hava tiyatrosudur.

ISO-YAYA-42 standardi (hayali, ama ciddi gorunuyor) sunu soyler:

1. Isik renktir.
2. Renk duygudur.
3. Duygu danstir.
4. Dans, kornadan daha insancildir.

## Kurulum

Python 3 yeter. Baska hicbir sey istemiyoruz. Bagimlilik kapitalizmine hayir.

```bash
python yaya.py
python yaya.py 8
```

Ikinci sayi kac tur dans edilecegini belirtir. Varsayilan 5'tir. 5, kutsal bir tur sayisidir cunku parmak sayisidir.

## Cikti ornegi

```
-- Tur 1/5 --

=== YAYA PROTOKOLU ===
Isik        : KIRMIZI
Performans  : horon titremesi (Karadeniz ruzgari opsiyonel)
Saha notu   : Yaya butonu zaten psikolojiktir.
Karar       : DURMA. Ritim tut.
=======================
```
